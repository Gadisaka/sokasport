# Game Management Module

## Overview

This module manages sports events and betting markets.

---

## Match Source

Matches are imported from:

Sports Betting API

---

## Admin Controls

Admin can:

- Enable match
- Disable match
- Suspend betting
- Close betting
- Override match results (tickets with selections on that match are recalculated based on the updated result)

---

## Market Control

Admin manages:

- Market availability
- Odds monitoring
- Risk limits

---

## Betting Limits

Admin configures:

- Minimum bet amount
- Maximum bet amount
- Maximum winning amount
- Minimum deposit
- Maximum deposit
- Minimum withdraw
- Maximum withdraw

---

## Error Control

Admin may disable matches when:

- Incorrect odds detected
- API error
- Suspicious betting activity
