# Reports System

## Overview

Reports provide financial and operational insights.

---

## Available Reports

Admin can view:

- Transaction reports
- Wallet reports
- Ticket reports
- Payout reports
- Cancelled ticket reports
- Bonus reports
- Cashback reports
- Cashout reports
- Deposit bonus reports
- Registration bonus reports

---

## Report Data

Reports must include:

- date
- user
- transaction type
- amount
- status
- reference id

---

## Access Control

Admin → Full reports

Financial Support → Payment reports

Agent → Branch reports only
